# JEE Distributed Systems

Educational repository covering core Java Enterprise Edition concepts through hands-on practical projects.

## Projects

### TP1: Dependency Injection & Inversion of Control

Demonstrates four approaches to DI/IoC using Spring Framework 6.

- Static / Tight Coupling
- Dynamic / Reflection-based injection
- Spring XML configuration
- Spring Annotation-based configuration

**Tech:** Java 17, Spring Framework 6.1.4, Maven

### TP2: Spring Data JPA & Hibernate

Two Spring Boot applications demonstrating JPA with Spring Data JPA:

- **AdilHammadHospital** - Hospital management with Patient, Medecin, RendezVous, Consultation entities
- **AdilHammadJpaSpringBoot** - Simplified Patient management CRUD

**Tech:** Spring Boot 3.2.3, Spring Data JPA, H2/MySQL, Lombok, Java 17
